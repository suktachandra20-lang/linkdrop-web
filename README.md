# 🔗 LinkDrop - Bio Link & Analytics Manager

LinkDrop is a modern full-stack web application designed to consolidate all your important links into one stylish, shareable bio page with real-time click analytics.

---

## 🚀 Key Features

* **Dynamic Bio Links:** Easily create, store, and manage your personalized profile page (`/u/username`).
* **Real-time Click Analytics:** Track user engagement with live click counters on your dashboard.
* **Authentication & Security:** Secure registration and login using JWT (JSON Web Tokens) and bcrypt password hashing.
* **Responsive Dashboard:** Manage links seamlessly across both desktop and mobile devices.
* **Production Live Deployment:** Deployed with Vercel for Frontend and Render for Backend.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, React Router, Vite, CSS3
* **Backend:** Node.js, Express.js, JWT Authentication
* **Database:** MongoDB Atlas (Mongoose ORM)
* **Hosting Platforms:** Vercel (Frontend), Render (Backend)
